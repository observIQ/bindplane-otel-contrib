# azureblobpolling

## Internal Telemetry

The following telemetry is emitted by this component.

### otelcol_azureblobpolling.records.consumed

Number of records parsed from blobs (attempted). On metrics and traces pipelines the count is data points and spans respectively.

| Unit | Metric Type | Value Type | Monotonic | Stability |
| ---- | ----------- | ---------- | --------- | --------- |
| {record} | Sum | Int | true | Alpha |

#### Attributes

| Name | Description | Values | Semantic Convention |
| ---- | ----------- | ------ | ------------------- |
| blob_format | The configured blob payload format the records were read from. | Any Str | - |

### otelcol_azureblobpolling.records.emitted

Number of records successfully forwarded to the next consumer. The gap below records.consumed is malformed records dropped during json/NDJSON line framing (records-json quarantines a bad blob instead). On metrics and traces pipelines the count is data points and spans respectively.
